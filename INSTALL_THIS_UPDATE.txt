INSTALL
1) In VS Code, open the Arcalogix marketing website repository.
2) Extract this ZIP. Copy the app/ and components/ directories into the
   matching paths in the repo; choose overwrite for the files in this update.
3) Run npm run typecheck and npm run dev (or npm run build) in your repo.
4) Test the homepage, About page, all CTAs, and favicon in a new browser tab.
5) Commit and push changes to GitHub; Vercel will deploy the updated files.

The browser can cache favicons. After deploy, hard-refresh or open an incognito
window; Google Search result favicon updates can take longer to propagate.
