# Arcalogix.ai — Recommended Changes and Implementation Notes

## Positioning
Lead with **Making places machine-readable**; immediately define it as transforming building information into structured, reusable spatial records that software and AI can query. Retain **spatial intelligence infrastructure for the built environment** as the category description.

## Priority changes
1. Change the homepage hero and opening metadata to explain machine-readability and enterprise outcomes.
2. Make Arch!e → AxSIM → AxLayout / integrations the visible technical architecture.
3. Add a verified example of a space object, attributes, adjacency and an actual query result.
4. Add an explicit availability matrix: available now, available with scoped integration, development priority.
5. Add a dedicated /technology/axsim page: data structures, IDs, provenance, source verification, supported formats, and planned semantics.
6. Add /enterprise/security and /integrations pages with only independently confirmed details.
7. Publish a customer-approved case study only after written authorization. Do not name BCG or imply IBM partnership without approval.
8. Preserve current production pricing and submission flows in the existing site; this prototype intentionally does not invent new contract terms.
9. Validate redirects/canonical URLs and sitemap on the production deployment.

## Delivery notes
This ZIP contains a standalone static **concept implementation**, not the existing site's source code. It should be merged into the production stack by the site developer, not deployed blindly as a replacement. All roadmap items are explicitly qualified.
